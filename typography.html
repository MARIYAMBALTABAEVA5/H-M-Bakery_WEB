Responsive Typography

This page has one job: show that heading and paragraph sizes change at three breakpoints using nothing but plain CSS @media queries (no Bootstrap on this page). Resize the browser window, or open it on a phone and a tablet, to see the text grow.

Mobile (below 600px)

On a narrow phone screen, the heading and body text start small and compact so nothing wraps awkwardly or overflows the viewport.

Tablet (600px and up)

Once the screen is at least 600px wide, the font sizes step up to a medium size, taking advantage of the extra horizontal space a tablet or a small laptop window provides.

Desktop (1024px and up)

On a full desktop monitor (1024px and wider) the headings and paragraph text scale up once more to their largest size, matching the greater screen space and typical reading distance of a desktop display.

How it works: the base CSS rules (no media query) define the mobile sizes. A @media (min-width: 600px) query overrides them for tablets, and a @media (min-width: 1024px) query overrides them again for desktop — a mobile-first approach.
