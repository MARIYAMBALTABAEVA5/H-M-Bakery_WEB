# H&M Bakery — Frontend Assignment 4

This project extends Assignment 3. Open `index.html` in a browser (or use VS Code Live Server).

## JavaScript features
1. **Form validation:** `contact.html` — demo registration form validates required name, email, password length >= 8 and matching confirmation. No server/account creation.
2. **Accordion:** `index.html` — FAQ questions open and close with CSS transitions.
3. **Popup form:** Subscribe button on all pages opens a modal, closes by X, backdrop or Escape. Demo only; no email is stored.
4. **Background color:** Button on all pages cycles through four colors.
5. **Current date/time:** Live clock on all pages updates every second.

Main logic: `js/script.js`; styles: `css/style.css`. All original Assignment 3 HTML pages and images remain.
