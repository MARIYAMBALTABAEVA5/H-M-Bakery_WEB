How it works: .card-group-mq is a flex container with flex-wrap: wrap. Each card starts at flex: 1 1 100% (full width = stacked, mobile default). A @media (min-width: 600px) query switches that to 50% (two per row, tablet), and a @media (min-width: 1000px) query switches it again to 33.333% (three per row, desktop).
